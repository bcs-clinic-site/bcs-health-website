When adding images, please make sure to follow this format: 
(##. (YYYY_M_DD) Name of Event)
Ex: 14. (2025_12_20) December Clinic
The number is important, this allows the website to order the images based on most recent event. A higher number means the event is more recent

Every instance of _ will be replaced with /, so (2025_12_20) December Clinic will become (2025/12/20) December Clinic
This will only affect anything within parentheses (), so you can include underscores anywhere else

Please put the event in the cooresponding folder depending on the type of event:
Clinic images will appear in https://bcshealthclinic.org/services/appointments 
Education images will appear in https://bcshealthclinic.org/involved/education 
Outreach images will appear in https://bcshealthclinic.org/involved/outreach
Symposium images will appear in https://bcshealthclinic.org/symposium/gallery
